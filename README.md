# arbolesdenavidad.mx

Repositorio de operación digital: sitio web, contenido de Instagram, marca y prospección B2B.

## Estructura
```
PROMPT-MAESTRO.md              Prompt para pegar en Claude Code
docs/
  CONTEXTO-NEGOCIO.md          Fuente de verdad del negocio
  INVESTIGACION-MERCADO.md     Datos verificados con fuente
  INVENTARIO-FOTOS.md          Clasificación del acervo fotográfico
contenido/
  instagram-perfil.md          Bio, nombre, configuración de cuenta
  primeros-posts.md            Los 6 primeros posts con copy listo
assets/
  marca/                       Logo, isotipo, foto de perfil (PNG y SVG)
  flyers/                      Flyer de preventa (PNG y SVG editable)
  fotos-historicas/            24 fotos de temporadas anteriores
```

## Regla número uno
Cero datos inventados. Precios, fechas y contactos van como placeholder hasta que se
confirmen. Ningún claim de producto sin fuente en `docs/CONTEXTO-NEGOCIO.md`.
